# gke-cluster

VPC-native Google GKE cluster with Workload Identity and separately-managed node pools.

## Usage

```hcl
module "gke" {
  source = "../../modules/gke-cluster"

  project_id = "my-gcp-project"
  name       = "dev-gke"
  region     = "europe-west3"

  node_pools = {
    default = {
      machine_type   = "e2-standard-2"
      min_node_count = 1
      max_node_count = 3
      spot           = true
    }
  }
}
```
