# vsphere-vm

Clone a VMware vSphere VM from a template with guest customization and optional data disks.

## Usage

```hcl
module "app_vm" {
  source = "../../modules/vsphere-vm"

  name       = "dev-app-01"
  datacenter = "Datacenter"
  cluster    = "Cluster"
  datastore  = "datastore1"
  network    = "VM Network"
  template   = "ubuntu-2204-template"

  num_cpus     = 2
  memory_mb    = 4096
  ipv4_address = "10.0.10.21"
  ipv4_gateway = "10.0.10.1"

  disks = [{ label = "data", size_gb = 50 }]
}
```
