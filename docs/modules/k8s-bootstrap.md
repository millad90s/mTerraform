# k8s-bootstrap

Install post-cluster addons (ingress-nginx, cert-manager, Argo CD, Falco) via Helm.

## Usage

```hcl
# The helm/kubernetes providers must be configured in the calling stack and
# pointed at the target cluster before using this module.
module "addons" {
  source = "../../modules/k8s-bootstrap"

  ingress_nginx = { enabled = true }
  cert_manager  = { enabled = true }
  argocd        = { enabled = false }
  falco         = { enabled = false }
}
```
