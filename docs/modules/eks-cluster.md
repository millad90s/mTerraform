# eks-cluster

Amazon EKS control plane, cluster/node IAM roles, and managed node groups.

## Usage

```hcl
module "eks" {
  source = "../../modules/eks-cluster"

  cluster_name = "dev-eks"
  subnet_ids   = module.vpc.private_subnet_ids # from your VPC stack

  node_groups = {
    default = {
      instance_types = ["t3.large"]
      capacity_type  = "SPOT"
      desired_size   = 2
      min_size       = 1
      max_size       = 3
    }
  }

  tags = { Environment = "dev" }
}
```
