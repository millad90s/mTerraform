# proxmox-lxc

Provision an LXC container on Proxmox VE via the bpg/proxmox provider.

## Usage

```hcl
module "ct" {
  source = "../../modules/proxmox-lxc"

  hostname         = "dev-ct-01"
  node_name        = "pve"
  template_file_id = "local:vztmpl/ubuntu-22.04-standard_22.04-1_amd64.tar.zst"

  cores     = 1
  memory_mb = 512

  disk = {
    datastore_id = "local-lvm"
    size_gb      = 8
  }

  ip_config       = "10.0.10.31/24"
  gateway         = "10.0.10.1"
  ssh_public_keys = [file("~/.ssh/id_ed25519.pub")]
}
```
