# openstack-storage

Manage OpenStack Cinder block volumes and optional attachment to instances.

## Usage

```hcl
module "storage" {
  source = "../../modules/openstack-storage"

  volumes = {
    dev-data = {
      size_gb     = 50
      volume_type = "ssd"
      instance_id = module.app_vm.id   # attach to an instance
      device      = "/dev/vdb"
    }
  }
}
```
