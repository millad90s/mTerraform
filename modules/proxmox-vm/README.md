# proxmox-vm

Provision a QEMU/KVM VM on Proxmox VE (clone + cloud-init) via the bpg/proxmox provider.

## Usage

```hcl
module "app_vm" {
  source = "../../modules/proxmox-vm"

  name              = "dev-app-01"
  node_name         = "pve"
  clone_template_id = 9000
  cores             = 2
  memory_mb         = 4096

  disk = {
    datastore_id = "local-lvm"
    size_gb      = 32
  }

  ip_config       = "10.0.10.21/24"
  gateway         = "10.0.10.1"
  ssh_public_keys = [file("~/.ssh/id_ed25519.pub")]
}
```
