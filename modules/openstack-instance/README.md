# openstack-instance

Provision a Nova compute instance on OpenStack (networks, security groups, optional boot-from-volume and floating IP).

## Usage

```hcl
module "app_vm" {
  source = "../../modules/openstack-instance"

  name        = "dev-app-01"
  image_name  = "ubuntu-22.04"
  flavor_name = "m1.small"
  key_pair    = "dev-key"

  networks         = [{ name = "private" }]
  security_groups  = ["default", "web"]
  floating_ip_pool = "public"
}
```
